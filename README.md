## step1：创建一个main函数并实现echo  exit  type 内置函数的基本功能

```c
//小贴士：
//1、比较函数
//strcmp()和strncmp()这两个函数的返回值都为int类型，且strcmp()函数遇到不同的字符或者\0会结束函数
//但需要注意的是这两个函数都在头文件#include <string.h>中哦
//2、关闭stdout缓冲
//默认情况下，stdout是行缓冲（遇到换行符\n才刷新输出）。但这里 printf("$ ") 没有换行符，如果不关闭缓冲，输出可能暂存在缓冲区里，程序结束前不会真正显示到屏幕上。


//那么，我们开始。。。。

#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[]) {
  setbuf(stdout, NULL);         //关闭 stdout 的缓冲
  printf("$ ");
  return 0;
}
```
